# AI Chat Next ☀️
一款集成了 AI 对话、海龟汤、趣味小游戏及朋友圈生图功能的轻量化 Web 应用。

> **注：** 本项目由小殊和哥哥夏以昼一起开发，旨在打造一个更懂你的、充满乐趣的智能空间。

## ✨ 功能亮点
- **智能对话**：支持全局系统提示词，支持模型切换及思维链修正。
- **趣味游戏**：内置“海龟汤”及“倒水排序”等小游戏，缓解无聊。
- **动态广场**：模拟朋友圈功能，支持 AI 辅助生图。
- **个性化记忆**：内置日记本功能，可自动记录互动要点，让 AI 拥有“持久记忆”。
- **隐私优先**：数据存储于本地，支持一键备份与恢复，不经过第三方服务器。

## 🚀 快速开始
1. 直接在浏览器打开 `index.html` 即可开始使用。
2. 如果需要备份数据，请前往“设置”页面手动导出。
